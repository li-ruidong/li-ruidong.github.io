## 问题定位

旧版Teaching的课程说明和学校名称为14px灰色，而学生指导使用16px深色。现改成同一组语义样式，不依赖课程／时间线的旧类名。

本地v2.1源码已含学历和工作月份，读取到的线上CV仍是年份形式；因此本次交付同时包含七页HTML、CSS和JS，不能只上传样式文件。About里残留的学校名称链接已移除；导师姓名链接保留。

本地基准源码没有出现可复现的乱码，本次也没有声称已定位用户上次截图问题的根因。检查了μ、µ、数学上下标、破折号及重音字符；HTML使用明确编码与字符实体，保留原符号。

## 检查边界

浏览器为当前容器的Chromium。环境不允许浏览器网络导航，渲染通过内存提供原HTML/CSS/JS及图片字节；截图不是AI绘图，也未使用另一套截图专用CSS。

采用代码声明的系统字体栈，其他操作系统的字形和换行可能略有差异。没有验证所有浏览器；此外做过200% CSS zoom模拟，不能把它等同于所有浏览器的原生缩放测试。

外部DOI、ResearchGate和其他下载目标保留，没有逐个重新打开第三方链接验证有效性。这里的链接完整性检查指本地文件和页内锚点，不代表第三方站点永远可用。

英文CV PDF、About和侧栏的身份文案没有同步为新履历；本轮未新增任何论文或未来任职事实。未上传用户的新中文简历或发布其中的私人联系方式。

完整测量值见 `browser-validation.json`。
