## 1. 不变项

本版是全站视觉和交付一致性修订，不是完整履历同步。About 与侧栏的原身份文案依照此前范围保留；未来任职信息和新增论文仍需单独更新。

## 2. 字体：一个字体栈，按信息角色分级

全站使用 `Arial, "Helvetica Neue", Helvetica, sans-serif`。不再使用 Trebuchet / Zilla Slab / Georgia 的混合搭配，不再下载在线字体。平台选择哪个已安装字体由系统决定，但同一浏览器中七页始终应用同一字体栈。

只保留期刊名、书目出版物名等具有明确意义的斜体，不再给页面标题、日期、学校名称添加装饰性斜体。

| 角色 | 桌面 | 手机 | 字重与样式 |
|---|---:|---:|---|
| 页面标题 H1 | 36px | 30px | 700，正体 |
| 主内容分区 H2 | 24px | 22px | 600，正体 |
| Publications 年份分组 | 20px | 18px | 600，正体；小于 H2 |
| 学校、课程、学生姓名、报告及奖励标题 | 16px | 16px | 700，`.entry-title` |
| 职位、学位、项目类型 | 16px | 16px | 400，`.entry-role` |
| 普通正文、论文引用段 | 16px | 16px | 400；引用中本人姓名700 |
| 日期、地点、机构附注、导师说明 | 14px | 14px | 400，`.entry-date` / `.entry-note` |
| Abstract / PDF / DOI | 14px | 14px | 400，与所在页正文同字体 |
| 侧栏 Contact 标签 | 18px | 手机隐藏标签 | 从属于侧栏，不作为正文 H2 |

同一种信息不能因页面或旧类名不同而变字体、字号或颜色。Teaching 的 Teaching Assistant 与 Final Year Project 同属 `.entry-role`；三条学校附注均属 `.entry-note`。不再使用 `.teaching-item p` 一刀切成小字、而 `.timeline-item p` 留大字的旧规则。

## 3. 间距与对齐

| 关系 | 间距 |
|---|---:|
| 引用正文 → 资源行 | **2px** |
| 条目标题 → 职位／附注 | 2px |
| 日期 → 地点 | 2px |
| 论文年份 → 该组第一条 | 8px |
| 普通段落之间、H2 → 第一条 | 12px |
| 相邻条目 | **16px** |
| 页面标题 → 内容 | 24px |
| 论文年份组之间 | 24px |
| 不同分区之间 | **32px** |
| 最后内容 → 页脚 | 48px |

这些值表示元素边界之间的布局间距，字形可见边缘还受到字体与行高影响。间距由一个容器或一个相邻关系负责，不叠加上下留白。

CV、Teaching、Activities 共用 `.entry-item`：144px 元信息列、24px 列间距、自适应正文列。窄屏把日期放在正文上方，间隔4px；不把日期挤成两行。News 使用72px短日期列。

Publications 编号列36px、右对齐。正文与资源行共用左边界，桌面列间距12px，手机8px。作者 → 题名 → 期刊连续书写，自然换行；资源入口另起一行。编号与正文首行顶端、行高相同。摘要面板在资源行下展开，不能推动同条 PDF / DOI。

正文左对齐，不两端对齐，不靠缩小字、截断长题名或硬插换行压缩页面。

## 6. 审美细节

导航内容与页面外层网格对齐，不再让品牌名独自贴浏览器左边。侧栏学术图标采用同一青绿色线性视觉，去掉互相竞争的彩色底和明显阴影。头像保留原图，用轻边线取代阴影。没有增加宣传式卡片、渐变、论文缩略图或新的栏目。

## 7. 编码与稳定性

七页都在文档头部明确声明 UTF-8；非ASCII文本以标准HTML数字字符实体输出，浏览器仍显示原来的 μ、µ、上下标、破折号和重音字符，不替换成近似字母。CSS 声明 UTF-8，脚本中的版权符号使用 Unicode 转义。

在基准 v2.1 的 Publications 源码和本次渲染中没有复现用户上次报告的乱码，没有把尚未确定的原因归结为某个字体或上传操作。本版加强编码保护，检查字符和真实渲染，不宣称已定位原故障根因。

导航和个人信息已写入静态 HTML；JavaScript 只增强手机菜单和摘要交互。脚本不可用时，七个导航链接、侧栏和原生摘要仍可访问。

共享源片段位于 `includes/header.html` 和 `includes/profile.html`；修改后运行 `python tools/sync_shared.py` 同步七页，避免手工维护出现差异。CSS 只维护 `assets/css/academic-site.css`，JS 只维护 `assets/site.js`，七页引用使用同一版本标识。
